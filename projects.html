Data / NLP

NFL Sentiment Analysis

Scraped over 17,000 ESPN and NFL team articles on 93 NFL players using Python and BeautifulSoup, then compared quantitative on-field performance data against qualitative media sentiment to determine whether press coverage aligns with actual results. Sentiment scored using DeBERTa.

Python BeautifulSoup Pandas MongoDB DB Browser DeBERTa

We used BeautifulSoup to scrape ESPN and NFL articles, structured and stored the data in MongoDB, cleaned and analyzed it with Pandas using DB Browser for inspection, then ran sentiment scoring through DeBERTa to quantify how media portrayed each player against their on-field stats.
